# Fotografías pendientes — Transformación

REALISTIC IMAGE ASSETS REQUIRED. La imagen base del BMW es temporal; no demuestra las cinco modificaciones.

Añadir aquí cinco fotografías `.webp`:

| Estado | Archivo |
| --- | --- |
| Frente y ópticas | transformation-front.webp |
| Rin delantero y postura | transformation-front-wheel.webp |
| Línea lateral | transformation-side.webp |
| Silueta superior | transformation-roof.webp |
| Rin trasero y cierre | transformation-rear.webp |

Los cinco archivos deben mostrar **el mismo BMW**, con modificaciones reales o edición fotográfica coherente, no piezas dibujadas. Mantener cámara, perspectiva lateral, posición, escala, iluminación y encuadre respecto a `../transformation-bmw-desktop.webp` (3840 × 2160). Conservar el fondo transparente/negro y la alineación de los hotspots.

La importación detecta los archivos empaquetados; si falta uno, su estado conserva la fotografía base. No solicita URLs inexistentes. Las imágenes diferentes se precargan y comparten la misma caja con crossfade de 320 ms (sin animación cuando se solicita movimiento reducido). No sustituir por fotografías del Audi ni por decoración SVG/CSS.

Después de añadir assets, verificar las cinco selecciones en 1440, 1024, 768, 430, 390 y 360 px antes de declarar realismo visual PASS.
