# UP GRADE 79 - V3 Showroom

Web premium para UP GRADE 79 con estética oscura de showroom, hero inmenso con vehículo protagonista, tipografía editorial, acento azul/cian y secciones estilo atelier/contacto.

## Correr local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Assets principales

- `src/assets/images/hero-bg-desktop.webp`
- `src/assets/images/hero-bg-mobile.webp`
- `src/assets/images/project-01.webp`
- `src/assets/logos/upgrade79-logo.png`

Para usar una foto real del carro del cliente, reemplaza `hero-bg-desktop.webp` y `hero-bg-mobile.webp` por una composición oscura de showroom o una imagen optimizada con el carro ya integrado.
